# 智核项目商业与模型方案精简版

日期：2026年11月17日

**总体方案：使用 Qwen 系列完成教学内容生产，以教师订阅和机构年度服务获得收入，先通过真实备课试点验证效果，再扩大推广。** 以下价格、用量和推广安排均为建议方案，尚未代表已成交、已盈利或完成模型切换。

## 一 模型选择

| 分工 | 暂定模型 | 北京地域官方 API 原价 |
| --- | --- | --- |
| 意图理解、需求补充 | [Qwen3.7-Flash](https://help.aliyun.com/zh/model-studio/qwen3-7-flash) | 每百万Token：输入0.20元、输出0.80元，单次输入≤32K |
| 识图、大纲、教案和课件生成 | [Qwen3.7-Plus](https://help.aliyun.com/zh/model-studio/qwen3-7-plus) | 每百万Token：输入2元、输出8元，单次输入≤256K |
| 教学配图、图片编辑 | [Qwen-Image-2.1-Turbo](https://help.aliyun.com/zh/model-studio/qwen-image-2-1-turbo) | 0.10元/张 |

选择理由：意图理解用Flash控制高频成本，识图与生成用Plus，将内容质量作为优先验证项；同平台便于接入和管理。采用 API 按量付费，前期不自建 GPU 推理集群。模型效果须用实际教材和课程任务验证。

## 二 成本计算

以约20页、4张配图的一套课件为测算样例。输入/输出Token为任务全程累计假设，不是固定页数换算或实测均值。

| 环节 | 输入/输出Token或图片数量 | 费用 |
| --- | --- | ---: |
| 意图理解 | 6000 / 900 Token | 0.00192元 |
| 内容生成 | 30000 / 40000 Token | 0.38000元 |
| 参考图片理解 | 6000 / 1000 Token | 0.02000元 |
| 配图 | 4张 | 0.40000元 |
| **三模型费合计** | — | **0.80192元，约0.80元** |

**模型预算：0.80192×1.25＝1.0024元，向上取整为1.01元/套。** 再预留辅助处理0.12元、增量导出与资源0.08元，按 **1.21元/标准备课额度** 测算直接用量成本。25%是预算余量；超长资料、多次重生成及额外音视频服务须另算。

完整经营还要覆盖人员、基础设施和推广。沿用原方案人员预算，并加入本方案假设：人员37820元＋基础云资源3000元＋推广4000元＋工具杂费1000元，**月固定成本约45820元**。这些预算需用真实投入核实。

## 三 盈利与定价

**机构年度服务为主，个人订阅和追加用量为辅。** 收费价值是帮助教师完成资料整理、教学设计、编辑导出和复用，并为机构提供管理与培训服务。

| 产品 | 建议价格 | 包含用量 |
| --- | ---: | --- |
| 个人基础版 | 29元/月 | 20个标准备课额度/月 |
| 个人进阶版 | 59元/月 | 40个标准备课额度/月 |
| 教研组年版 | 12000元/年 | 最多50个账号，共享300个额度/月 |
| 学校年版 | 36000元/年 | 最多200个账号，共享1200个额度/月 |

一个标准额度按上述任务预算设计，含最多4张配图；高消耗任务需预估并增加额度。机构账号共享用量，培训、维护和定制范围另行写清，不承诺无限生成。

**盈利要看完整成本。** 例如基础版每月使用10个额度，另预留2元直接服务支出、收入3%的支付退款准备，则每用户月贡献为：

```text
29－10×1.21－2－29×3%＝14.03元
```

若用满20个额度，贡献降为1.93元。只卖基础版时，覆盖45820元月固定成本，分别约需3266人或23741人。这是条件测算，不是销售预测。改用Plus后，29元档满额贡献较薄，正式销售前需验证并调整价格或额度；尚未证明能收回研发投入。

## 四 推广与执行

**推广顺序：教师体验 → 教研组付费试点 → 学校年度服务。**

| 阶段 | 主要工作 | 判断依据 |
| --- | --- | --- |
| 第1个月 | 完成三模型接入、费用记录；邀请约30名目标教师体验真实课程 | 能否完成可授课成果，人工修改和总耗时如何 |
| 第2个月 | 改进主要问题，通过工作坊、授权案例和教研交流推进团队试点 | 是否跨周复用，是否愿意实际付款 |
| 第3个月 | 复盘成本、服务工时和渠道，形成明确年度服务包 | 单位贡献、续费意愿和交付能力是否支持扩大 |

首期不大规模买量。推广重点看完成任务、重复使用、付款和续费，不只看注册量；试用额度、演示和推荐奖励也应记成本。

**执行前优先完成三件事：**

1. 代码落实意图、视觉和生图分流；现有配置不能仅改模型名就视为接入完成。
2. 实现任务预算、图片额度和有限重试，按真实账单修正1.21元的单位预算。
3. 用教师试点验证收费价值；正式价格与服务范围确认后再销售，推广只使用实际效果数据。

原方案的开发期预算约12.13万元、项目报价约52.93万元，属于不同口径，不能直接相减认定净利润，也不能当作学校订阅价格。

模型价格核对日期为2026年11月17日；商业数字为试点假设。详细公式、代码差距、资金预算和资料依据见[完整方案](./智核项目_盈利推广成本与模型选择完整方案.md)。
