# Design System: 交互式知识图结构

> 一套用于呈现个人知识、研究项目、作品谱系或组织关系的交互式图结构。它以层级树为骨架、跨层连接为补充，通过节点形状、线型、渐进过滤和可拖拽力导向布局，让复杂关系保持可读。

参考交互：[Andrew Trousdale](https://andrewtrousdale.com/?ref=minimal.gallery)。本文提取的是可复用的图结构设计语言，不绑定原网站的人物、内容、背景或固定配色。

## 1. 核心体验

图结构不是一次性展示完整数据库，而是允许用户逐步探索：

```text
全局概览
→ 选择节点
→ 保留祖先路径
→ 展开当前节点的直接子级
→ 补充跨域关联节点
→ 查看详情或继续深入
```

- **先看关系，再读内容：** 图提供知识空间的整体方向，详情面板负责解释。
- **渐进披露：** 默认只展示重要节点，不把全部数据同时塞入画面。
- **保持上下文：** 进入节点后仍保留从根节点到当前节点的路径。
- **类型可辨：** 不同类别使用不同几何形状，而不是只靠颜色。
- **关系可辨：** 实线、虚线和点线分别表达不同关系。
- **布局可触摸：** 节点可拖动，连线随节点实时重算。
- **系统会回稳：** 拖拽结束后，力导向模拟重新寻找平衡。

## 2. 数据模型

推荐节点数据：

```ts
type GraphNode = {
  id: string;
  uri: string;
  title: string;
  summary?: string;

  type:
    | "root"
    | "information"
    | "path"
    | "research"
    | "initiative"
    | "artifact";

  children?: GraphNode[];
  connectedNodeIds?: string[];

  isFeatured?: boolean;
  isHighlighted?: boolean;
  isSecondary?: boolean;

  originDate?: string;
  expirationDate?: string;
  themeId?: string | number;
};
```

### 关系类型

- **Parent / Child：** 树形层级中的直接父子关系。
- **Ancestor Path：** 从根节点到当前节点的导航上下文。
- **Connected：** 不属于当前层级，但与当前节点相关的跨域连接。
- **Secondary：** 存在于图中但视觉优先级较低的节点。
- **Highlighted：** 需要提示用户关注的节点。

跨域关系必须明确存储，不能仅通过屏幕距离暗示。

## 3. 图层结构

推荐使用“SVG 连线 + HTML 节点”的混合结构：

```html
<div class="graph">
  <svg class="graph-lines" aria-hidden="true"></svg>
  <div class="graph-nodes"></div>
</div>
```

### SVG 连线层

- 占据整个图容器。
- 只绘制关系路径。
- 不承担文字与点击区域。
- 每次力导向 tick 更新 `path d`。

### HTML 节点层

- 每个节点是独立的绝对定位元素。
- 可使用真实 `<button>` 或 `<a>` 获得键盘和辅助技术支持。
- 节点中心与 SVG 连线端点使用同一坐标。
- 标签使用 HTML 排版，避免 SVG 文本换行与字体测量问题。

### 图层顺序

```text
背景
→ 连线 SVG
→ 节点图形
→ 节点标签
→ 详情面板
```

连线不得覆盖节点图形和标签。

## 4. 图容器布局

### 桌面端

- 图容器覆盖可用视口高度。
- 当右侧存在详情面板时，力导向中心放在左侧约 `55%` 视口区域内。
- 图的 SVG 仍可覆盖整个容器，但节点的中心力应指向内容可用区域。
- 推荐：

```js
graphWidth = viewportWidth * 0.55;
graphHeight = viewportHeight - edgeBuffer;
center = [graphWidth / 2, graphHeight / 2];
```

- 图和详情面板之间保留明显空白，不使用硬边框切割。
- 图容器进入时可从右侧 `10vw` 缓慢归位：

```css
@keyframes graph-in {
  from { transform: translateX(10vw); }
  to   { transform: translateX(0); }
}
```

推荐整体进入时长约 `3000ms`，但节点和连线应有独立淡入节奏。

### 无详情面板

- 将中心力移动到完整容器中心。
- 不直接把原图机械放大；重新启动模拟，让节点自然利用新增空间。

## 5. 节点尺寸与点击区域

所有节点使用一致的交互热区：

```css
.graph-node {
  position: absolute;
  width: 36px;
  height: 36px;
}
```

- `36 × 36px` 是视觉图形外的交互容器。
- 实际图形约 `20–26px`。
- 节点坐标表示容器左上角，连线端点需要加半个节点尺寸：

```js
centerX = node.x + nodeSize / 2;
centerY = node.y + nodeSize / 2;
```

- 如果产品需要更严格的触控要求，可将热区扩展到至少 `44 × 44px`，但保持视觉图形尺寸不变。

## 6. 节点类型与几何

类型首先由几何表达，颜色只负责状态强调。

| 类型 | 几何 | 推荐尺寸 | 含义 |
|---|---|---:|---|
| Root | 多瓣星形 | `21px` | 图谱起点、身份或系统核心 |
| Information | 实心圆 | `20px` | 说明、联系或系统信息 |
| Path | 六边形 | `24px` | 领域、主题路径或分类 |
| Research | 正方形 | `20px` | 研究、调查或实验 |
| Initiative | 三角形 | `24 × 20px` | 计划、组织或行动 |
| Artifact | 圆形轮廓 | `20px` | 作品、结果或具体产物 |

### Path 编号

主要路径节点可在六边形内部显示短编号：

- 字号约 `11px`。
- 居中对齐。
- 编号表达当前视图中的主要路径顺序，不应被误解为数据库 ID。
- 视图过滤后可重新编号。

### Root 动态

根节点可使用非常缓慢的旋转：

```css
animation: root-rotate 10s linear infinite;
```

只有根节点使用持续旋转。其他节点保持静止，避免整张图显得躁动。

## 7. 节点标签

标签位于节点下方居中：

```css
.node-label {
  position: absolute;
  top: 100%;
  left: 50%;
  width: 150px;
  transform: translate(-50%, -3px);
  text-align: center;
  pointer-events: none;
}
```

### 标题

- 推荐 `13–14px` 无衬线字体。
- 紧凑行高约 `1.45`。
- 最多两行。
- 文字后可使用与画布颜色一致的小面积底色，避免连线穿过文字。
- 背景块只包裹文字，不形成卡片。
- 圆角约 `3–5px`。
- 内边距约 `1–4px`。

### 摘要

- 字号约 `11px`。
- 全大写或小型大写形式。
- 字距约 `0.05em`。
- 使用次要文字色。
- 默认透明度为 `0`。
- 节点悬停、当前节点或根节点时淡入。
- 推荐淡入时长 `200ms`。

### 标签密度

- 重要节点默认显示标题。
- 次要或高密度节点可只在悬停、聚焦或选中时显示标签。
- 不通过缩小到不可读字号解决标签重叠。
- 标签发生严重碰撞时，应减少默认可见节点，而不是隐藏所有关系。

## 8. 连线语法

基础连线：

```css
.graph-link {
  fill: none;
  stroke: var(--graph-ink);
  stroke-width: 1px;
}
```

### 线型语义

| 关系 | 线型 | 颜色 | 线宽 |
|---|---|---|---:|
| 主层级关系 | 实线 | 主墨色 | `1px` |
| Initiative 关系 | `5 5` 虚线 | 主墨色 | `1px` |
| Secondary 关系 | `5 5` 虚线 | 次要灰 | `1px` |
| Connected 跨域关系 | `2 10` 点线 | 次要灰 | `2px` |
| Information 关系 | 实线 | 主墨色 | `1px` |

不同线型必须对应稳定语义，不能随机装饰。

### 端点

- 线从节点几何中心连接到节点几何中心。
- 允许线穿到图标下方，由节点实色填充遮挡末端。
- 不使用箭头，除非业务确实需要表达方向。

## 9. 连线路径

### 直线

研究、行动、作品和信息节点优先使用直接连线：

```js
function straightPath(source, target) {
  return `M ${center(source)}
          L ${center(target)}`;
}
```

### 折线路径

主题路径节点使用四段折线，强调“路径”语义：

```js
const p1 = center(source);
const p4 = center(target);

const p2 = {
  x: source.x + (target.x - source.x) / 3,
  y: source.y + (target.y - source.y) / 3 + bend
};

const p3 = {
  x: source.x + 2 * (target.x - source.x) / 3,
  y: source.y + (target.y - source.y) / 3 + bend
};
```

- `bend` 推荐 `±30px`。
- 根据目标位于源节点上方或下方决定弯折方向。
- 折线中间部分接近水平，形成技术图纸般的结构。
- 不对所有连接使用曲线，否则节点类型差异会消失。

## 10. 力导向布局

推荐使用 D3 Force 或等价物。

### 参考参数

```js
forceLink
  .distance(70)
  .strength(0.1);

forceManyBody
  .strength(-400)
  .distanceMin(10)
  .distanceMax(300);

forceCenter(centerX, centerY);
```

- 桌面端连接距离约 `70px`。
- 小型容器可以缩短到约 `30px`。
- 较强的 `-400` 排斥力为标签留出空间。
- 最大作用距离约 `300px`，避免远端节点互相过度影响。
- 力布局负责获得自然构图，不负责解决所有标签重叠。

### 初始布局

- 不手工指定每个节点的最终绝对坐标。
- 节点进入后允许模拟逐渐冷却。
- 详情面板打开、容器尺寸改变或图被过滤后，将 `alpha` 提升到约 `0.3` 并重新启动。
- 不让模拟永远保持高能量；图应在短时间内稳定。

## 11. 节点拖拽

### 拖拽开始

```js
simulation.alphaTarget(0.3).restart();
node.fx = node.x;
node.fy = node.y;
```

### 拖拽过程

```js
node.fx = event.x;
node.fy = event.y;
```

- 节点跟随指针。
- 所有关联 SVG 路径在每个 tick 中实时更新。
- 其他节点受排斥力和连接力影响产生轻微让位。

### 拖拽结束

```js
simulation.alphaTarget(0);
node.fx = null;
node.fy = null;
```

- 释放固定坐标，让节点回到图结构的力平衡中。
- 节点不需要回到拖拽前的精确位置。
- 拖拽距离超过点击阈值时，不应同时触发节点打开。
- 支持鼠标和触摸拖动，但不得阻止必要的页面手势。

## 12. 悬停、聚焦与状态

### Hover / Focus

- 节点图形在 `100ms` 内放大到 `1.1`。
- 摘要标签在 `200ms` 内淡入。
- 不移动整个节点，不改变力导向坐标。
- 键盘聚焦必须获得与 hover 相同的信息。

### Highlighted

- 在图形中心添加 `4px` 提示点。
- 以 `1s` 周期在透明和可见之间轻微闪烁。
- 不改变整个节点颜色。
- 同时高亮的节点数量保持很少。

### Secondary

- 节点轮廓、文字和连线使用次要灰。
- 仍然可点击，不通过低透明度降到不可读。

### Connected

- 表示跨域关系。
- 使用次要图标和点状连线。
- 不与主要树形层级竞争。

### Current

- 当前节点使用类型对应的状态填充色。
- 图形中心可显示一个小型 `×`，提示再次点击可以关闭或返回。
- 当前节点摘要保持可见。
- 同一时间只能有一个当前节点。

### Visited

- 已访问节点标题可使用细删除线。
- 删除线颜色与节点当前主色或次要色一致。
- 不把节点永久置灰，避免与 Secondary 状态混淆。

## 13. 类型状态颜色

颜色不是节点类型的唯一编码，几何始终优先。

推荐基础令牌：

```css
.graph {
  --graph-surface: #f5f6f2;
  --graph-ink: #111111;
  --graph-muted: #888888;

  --graph-root-active: #ff5f1f;
  --graph-path-active: #7a8743;
  --graph-research-active: #bfa99f;
  --graph-initiative-active: #f7db45;
  --graph-artifact-active: #3573b6;
}
```

这些颜色只用于根节点或当前节点的小面积填充，不能扩展成大面积页面配色。

### 与背景的关系

- 普通节点内部填充应与图画布颜色一致。
- 节点轮廓与主文字使用高对比墨色。
- 次要关系使用中等对比灰色。
- 标签底色与画布一致，用来遮挡穿过文字的连线。
- 深色主题下反转明暗关系，但保留节点几何和线型语义。
- 不使用发光、渐变或阴影提升节点可见性。

## 14. 节点点击与渐进过滤

点击非当前节点后，构建一个局部子图：

1. 保留从根节点到当前节点的祖先链。
2. 保留当前节点。
3. 展开当前节点的直接子节点。
4. 直接子节点暂不递归展开后代。
5. 加入 `connectedNodeIds` 指向的跨域节点。
6. 将跨域节点标记为 `connected`。
7. 打开或更新详情面板。
8. 更新 URL，使当前视图可复制、前进和后退。

伪代码：

```js
subgraph = [
  ...ancestorChain(selected),
  selected,
  ...directChildren(selected),
  ...connectedNodes(selected)
];
```

点击当前节点或根节点：

- 清除当前选择。
- 恢复当前时间点下的全局概览。
- 关闭详情或切回索引面板。

不要在点击后隐藏所有上下文，只展示一个孤立节点。

## 15. 图更新与进入动画

系统维护上一帧的节点和边集合：

```js
previousNodes: Set<NodeId>
previousLinks: Set<EdgeId>
```

### 已存在元素

- 保持 `opacity: 1`。
- 不重复播放进入动画。
- 力布局可以平滑调整位置。

### 新节点

- 默认 `opacity: 0`。
- 从约 `500ms` 开始依次加入可见类。
- 节点之间错开约 `100ms`。
- 单个淡入时长约 `1000ms`。

### 新连线

- 默认 `opacity: 0`。
- 从约 `1000ms` 开始依次加入可见类。
- 连线之间错开约 `100ms`。
- 单条淡入时长约 `1000ms`。

节点先于连线出现，让用户先建立对象认知，再理解关系。

### 移除元素

- 数据退出时移除不再属于当前子图的节点和连线。
- 如果图变化较大，可增加短暂淡出，但总时长不能拖慢探索。

## 16. 详情面板关系

详情面板与图并列，而不是覆盖整个图：

- 面板展示当前节点的标题、介绍、分类和相关条目。
- 图保留当前节点及其关系上下文。
- 点击面板中的相关条目，应执行与点击图节点相同的过滤逻辑。
- 面板和图使用同一个 `uri` 作为状态主键。
- 浏览器返回操作应恢复前一个图状态。
- 面板打开或尺寸变化后，重新计算图中心并温和启动模拟。

详情面板不是图结构本身的一部分，可按项目内容自由设计。

## 17. 时间维度（可选）

如果节点具有时间属性，可加入时间滑块：

```js
visible =
  node.originDate <= selectedDate &&
  (
    !node.expirationDate ||
    node.expirationDate > selectedDate
  );
```

- 只展示在选定日期已经出现且尚未失效的节点。
- 时间变化后重新生成图数据并启动模拟。
- 滚轮可以按离散步长控制时间，但必须避免与页面正常滚动冲突。
- 时间不是所有图谱必需的功能；没有真实时间语义时不要添加。

## 18. 响应式

### 大于 `768px`

- 使用完整力导向图。
- 图和详情面板并列。
- 支持悬停、拖拽和动态过滤。

### 小于或等于 `768px`

参考方案直接隐藏图结构，改用结构化索引或树形列表：

- 节点标题成为可点击列表项。
- 按类型分组。
- 使用缩进或面包屑表达层级。
- 详情占据主要视口。

不要把桌面图谱直接缩小塞入手机：

- 标签会重叠。
- 触摸拖动与页面滚动冲突。
- 关系线难以辨认。
- 节点热区不足。

如果移动端必须保留图，可做独立的全屏探索模式，而不是嵌入正文。

## 19. 可访问性

- 节点使用 `<button>` 或 `<a>`，不要只使用无语义 `<div>`。
- 每个节点提供可访问名称：标题 + 类型 + 摘要。
- 当前节点使用 `aria-current="page"` 或 `aria-pressed="true"`。
- SVG 连线默认 `aria-hidden="true"`。
- 关系信息在详情或辅助列表中提供文本版本。
- 键盘用户可以 Tab 访问节点，并用 Enter 打开。
- Focus 状态与 Hover 状态视觉一致。
- 拖拽不是访问内容的必要条件。
- 减少动态效果模式下关闭根节点旋转、闪烁点和错峰淡入。

## 20. 性能规范

- SVG 只保存连线路径。
- HTML 节点数量保持在当前可理解范围，推荐同时可见 `8–30` 个。
- 用稳定的节点 ID 和边 ID进行数据绑定。
- 每个 tick 只更新节点 `left/top` 或 transform 与连线 `d`。
- 容器 resize 使用约 `200ms` 防抖。
- 图过滤后重启模拟，不为不变节点重新创建 DOM。
- 模拟冷却后停止不必要的持续刷新。
- 拖拽时将 `alphaTarget` 暂时提高，结束后恢复为 `0`。
- 高密度数据先聚合或过滤，不通过增加计算量强行全部显示。

## 21. 禁用模式

- 不用颜色作为唯一节点分类依据。
- 不把所有节点设计成相同圆点。
- 不默认展示整个数据库。
- 不让所有标签永久显示并互相覆盖。
- 不使用粗线、发光线和渐变连线。
- 不使用随机曲线制造“有机感”。
- 不让节点永远漂动。
- 不在拖拽结束后永久固定节点，除非产品支持保存布局。
- 不因拖拽触发误点击。
- 不在手机上机械缩小桌面图。
- 不隐藏祖先路径，让用户失去当前位置。
- 不使用无法通过文字解释的线型。
- 不为了视觉效果添加没有真实含义的时间轴。

## 22. 验收标准

- 用户无需阅读说明即可通过几何区分主要节点类型。
- 实线、虚线和点线具有稳定且可解释的关系语义。
- 默认图节点数量克制，标签基本可读。
- 点击节点后仍能看见根节点到当前节点的祖先链。
- 当前节点的直接子节点与跨域节点能被明确区分。
- 节点可拖动，相关连线在拖动过程中实时更新。
- 松手后图在短时间内重新稳定。
- Hover 与键盘 Focus 均能显示节点摘要。
- 新节点先于新连线错峰淡入，旧节点不重复闪烁。
- 当前节点、次要节点、跨域节点和已访问节点状态不混淆。
- URL、详情面板和图选中状态保持同步。
- 小屏设备使用可读的列表或独立探索模式。
- 图的关系存在等价文本表达，不依赖视觉连线才能理解。
