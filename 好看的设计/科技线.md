# Design System: PCB Energy Trace

## 1. 视觉主题与氛围

一种克制的深海科技视觉：近黑蓝画布、低亮度 PCB 走线和少量高速能量脉冲。整体应像精密电子设备内部的信号网络，而不是霓虹灯牌或游戏 HUD。

- **密度：** 低至中等（4/10）。画面必须留有大面积暗部和呼吸空间。
- **变化度：** 中等（5/10）。线路不完全对称，但保持理性、有序。
- **动态强度：** 中等（6/10）。背景持续流动，但不能抢夺前景内容注意力。
- **视觉关键词：** 深海、精密、冷静、低噪声、电子信号、工业科技。
- **核心原则：** 运动由光脉冲产生，结构由细线产生；禁止用装饰性圆球或密集图标制造“科技感”。

## 2. 色彩系统

### 基础色

- **Abyss Canvas** `#020817`：页面主背景，禁止使用纯黑 `#000000`。
- **Deep Circuit Field** `#031525`：中心区域的轻微提亮。
- **Ambient Depth** `#062438`：径向环境光最亮处，仅用于扩大空间纵深。
- **Circuit Trace** `#0A5268`：静态 PCB 基础线路。

### 能量色

- **Signal Cyan** `#00EAFF`：唯一高饱和能量色，只用于移动脉冲和极弱线路泛光。
- **Energy Core** `#FFFFFF`：脉冲中心的瞬时高光，不作为大面积文字或组件颜色。
- **Trace Glow** `#00D9FF`：基础线路的低透明度扩散光，透明度控制在 `0.10–0.16`。

### 色彩使用规则

- 高饱和青色占画面面积不得超过 `3%`。
- 静态线路始终比移动脉冲暗至少两个视觉层级。
- 不使用紫色、洋红、彩虹渐变或多色能量流。
- 不给按钮、卡片和正文添加青色外发光；发光仅属于背景中的移动能量。

## 3. 背景与空间层级

画面按以下顺序从后向前构建：

1. **深色画布：** `#020817`。
2. **径向环境光：** 中央使用 `#062438 → #031525 → #020817` 的低对比径向渐变。
3. **静态线路：** `1.5px` 暗青色细线。
4. **线路泛光：** 同路径复制一层，约 `3px`，透明度 `0.13`，模糊半径约 `3px`。
5. **移动能量：** `2.8px` 高亮脉冲，中心为白色，两侧过渡到青色和透明。

环境光不能形成明显光斑边界。它只负责让中心区域比边缘略亮，不能产生蓝色“大圆盘”。

## 4. PCB 线路语法

### 几何规则

- 线路以水平段为主，通过短对角线改变高度。
- 转向角只使用 `45°` 和 `135°`，模拟 PCB 走线。
- 单条线路建议包含 `3–6` 个水平段和 `1–3` 组斜向转折。
- 相邻线路保持足够垂直间距，禁止交叉、缠绕或形成随机蛛网。
- 线路应从画布边缘之外进入或离开，避免出现刻意的短线端点。
- 推荐 SVG 设计坐标系：`viewBox="0 0 1200 800"`。
- 全屏背景使用 `preserveAspectRatio="xMidYMid slice"`，保证铺满视口。

### 明确禁止

- 不在线路转折处添加圆球、圆环、焊盘或呼吸节点。
- 不使用箭头、粒子喷射、六边形装饰和随机数字标签。
- 不把线路做成等距网格；每条线需要有不同的节奏和长度。
- 不使用粗于 `4px` 的静态线路。

## 5. 能量脉冲设计

### 外观

能量不是一串均匀虚线，而是一段独立、具有明亮核心的光脉冲：

```text
透明 → 青色弱光 → 白色核心 → 青色弱光 → 透明
```

- 脉冲线宽：`2.8px`。
- 端点：圆头 `stroke-linecap: round`。
- 标准化路径：每条 SVG 路径设置 `pathLength="100"`。
- 脉冲比例：`stroke-dasharray: 11 89`，即约 `11%` 可见、`89%` 留空。
- 能量光晕：高斯模糊约 `1.8px`，再与清晰原线合并。
- 任意时刻每条线路只展示一段主要脉冲。

### 动画

```css
@keyframes flow {
  from { stroke-dashoffset: 100; }
  to   { stroke-dashoffset: 0; }
}
```

- 使用线性运动，表达稳定的数据或能量传输。
- 每条线路速度不同，建议范围 `6–13s`。
- 使用负延迟让页面加载时脉冲已经分布在不同位置，避免同时从起点出现。
- 相邻线路可交替使用正向和反向流动。
- 速度差异应自然，避免按整齐倍数排列。
- 动画必须无限循环，循环衔接处不能闪烁或跳变。

推荐参数：

| 线路 | 时长 | 延迟 | 方向 |
|---|---:|---:|---|
| Trace 01 | `7.2s` | `-1.1s` | 正向 |
| Trace 02 | `10.8s` | `-4.8s` | 反向 |
| Trace 03 | `6.4s` | `-3.2s` | 正向 |
| Trace 04 | `12.6s` | `-7s` | 反向 |

## 6. 排版与前景内容

当科技线路作为页面背景使用时：

- **标题字体：** `Geist`、`Satoshi` 或 `Outfit`，字重 `500–650`，紧凑字距。
- **正文：** `Geist` 或系统无衬线字体，行高 `1.6–1.75`，每行不超过 `65ch`。
- **数据与代码：** `Geist Mono` 或 `JetBrains Mono`。
- 主文字使用冷白色，但避免纯白大面积铺陈；推荐 `#E6F5F7`。
- 次要文字推荐 `#7895A1`。
- 内容区域可使用 `rgba(2, 8, 23, 0.72)` 的半透明底色提高可读性，但不添加厚重卡片阴影。
- 线路不得穿过重要文字的高对比核心区域；可通过遮罩降低内容背后的线路透明度。

## 7. 布局与响应式

- 桌面端推荐 `3–6` 条横向线路，避免平均分布。
- 移动端减少到 `2–4` 条线路，并保留较大的垂直留白。
- 线宽使用 `vector-effect: non-scaling-stroke`，防止缩放后变粗或变细。
- 页面必须禁止横向滚动。
- 背景 SVG 使用 `width: 100%; height: 100%`。
- 前景内容使用独立层，不直接写入线路 SVG 中。
- 若设备启用“减少动态效果”，允许暂停能量流，仅保留静态线路。

## 8. 性能规范

- 优先使用一个 SVG 管理全部线路。
- 路径存放在 `<defs>` 中，通过 `<use>` 复用；定义路径本身不携带 `.trace` 样式，避免覆盖实例层的能量样式。
- 发光使用少量 SVG filter，不为每个脉冲创建多个 DOM 粒子。
- 不使用 JavaScript 驱动逐帧动画；优先使用 CSS `stroke-dashoffset`。
- 同屏动态线路建议不超过 `8` 条。
- 模糊滤镜范围应受控，避免过大的 filter region。

## 9. 交互与可访问性

- 背景线路不承载点击行为。
- 装饰性线路组使用 `aria-hidden="true"`。
- SVG 可提供简短的 `aria-label`，例如“流动能量的 PCB 电路网络背景”。
- 动画不能造成快速闪烁；亮度变化频率保持稳定。
- 能量流不得影响按钮焦点、表单错误和状态提示的识别。

## 10. 禁用模式

以下视觉模式一律禁止：

- 转折点圆球、圆环、焊盘和呼吸灯。
- 满屏霓虹蓝、紫色渐变或赛博朋克彩虹光。
- 密集粒子、数字雨、扫描线同时叠加。
- 粗线、剧烈闪烁、速度完全同步。
- 每条线路等长、等距、等速的机械排列。
- 大面积文字外发光。
- 玻璃拟态卡片覆盖整个页面。
- 无意义的 HUD 刻度、雷达圈、六边形和装饰性英文代码。
- 使用 `top`、`left`、`width` 或 `height` 做逐帧动画。
- 为了“科技感”牺牲正文可读性。

## 11. 验收标准

最终画面应同时满足：

- 第一眼感受到冷静、精密的科技氛围。
- 静态截图依然具有清晰的线路层次。
- 动态状态能明显看到能量沿路径移动。
- 线路保持克制，前景内容仍是视觉主体。
- 画面中不存在圆球节点。
- 循环播放一分钟后没有明显跳帧、闪断或同步感。
